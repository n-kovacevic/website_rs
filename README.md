# Srpski portfolio

Srpska verzija portfolija objavljuje se putem GitHub Pages na <https://nkovacevic.rs/>.

Pokrenite `python3 -m http.server 8000` u ovom direktorijumu i otvorite
<http://localhost:8000/>. Sadržaj i izgled menjaju se direktno u datotekama
`index.html` i `style.css`. Engleska verzija je u repozitorijumu
`n-kovacevic/website_en`.
